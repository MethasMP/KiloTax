# Top-three fixes — 10 November 2026

## Changes

1. Restored a clean analyzer and passing product suite. The baseline had five analyzer issues and 11 test failures (518 passed). Removed unused test declarations, declared the existing XML parser as a direct dev dependency, and updated outdated UI tests to exercise the current task-first navigation and permission-aware tracking flow. Large-text navigation checks verify complete, unclipped labels and working destinations rather than forcing text onto one line.
2. Fixed false-success account deletion across the HTTP service, AppState and Settings. A failed `delete_user_account` RPC no longer attempts partial table deletion, signs the user out, or erases local records. Only server acknowledgement permits local cleanup. Settings reports failure and offers retry through the existing account controls. A failed logout after acknowledged deletion does not misreport the completed server transaction.
3. Added a continuous guest journey: Welcome → vehicle → manual trip → edit the original trip → manual expense → reconstruct AppState → verify saved records → generate PDF and XLSX. This exposed an unnamed custom back button in Trip detail; it now has the localized Back tooltip. Added a native integration entry point using a separate test-only preferences prefix and a native preference reload.

## Reproduce

```sh
flutter analyze --no-pub
flutter test --no-pub --concurrency=4
BUILD_FOR_DEVICE=1 flutter drive --profile --no-pub --publish-port \
  --driver=test_driver/integration_test.dart \
  --target=integration_test/release_main_journey_test.dart \
  -d 00008020-000244920E03802E
```

The wireless iPad needs `flutter drive --publish-port`; `flutter test` disables port publication and refuses to start a debug app on that wireless device. Native test preferences use `kiloclaim_release_smoke.` and do not clear normal user preferences. The manual-entry runner intercepts the unused native-telemetry channel so it cannot drain pending real trips or replace the real car pairing. This runner does not verify native automatic tracking.
