# Standard: Humanizer Writing Style

Apply the principles from `SKILL.md` (Humanizer) across all text, code docs, and responses:
- Avoid AI tells: no "not X but Y" staging, no forced triads, no one-line dramatic closers, no em/en dashes as universal connectors, no stock AI buzzwords (delve, robust, crucial, tapestry, pivotal, landscape), no decorative bolding on every list item, and no chatbot filler.
- Be direct, specific, and natural. State points plainly without inflated significance or borrowed authority.
